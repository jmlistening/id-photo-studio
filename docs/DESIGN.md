- 日期：2026-10-30
- 状态：v1 已实现；美颜、换正装、批量等为后续迭代

## 1. 意图

一个自己用的小工具：把任意照片裁成证件照尺寸、换成指定底色，人物本身不做任何修饰。不想装环境、不想注册账号、不想上传照片，也不想为此花钱。以后若想上线，同一份静态文件可以直接部署，不需要返工。

## 2. 目标

- Windows 上双击即用，不依赖 Python、Node、数据库或任何安装步骤。
- 电脑浏览器完整可用；手机可通过同一 Wi-Fi 访问，或把文件传到手机用浏览器打开。
- 任意照片都能处理：纯色底证件照、手机随手拍、复杂背景、HEIC、超大图、截图。
- 换底质量可用：纯色底边缘干净；复杂背景发丝可接受；抠不好能手动修。
- 输出尺寸准确、DPI 正确、能压到指定 KB，可直接用于报名/打印。
- 所有处理本地完成，照片不出设备。
- 功能一次做全：规格预设、裁剪、双引擎换底、手动修补、压缩、批量、全套导出、排版打印。

## 3. 非目标

- 默认不做美颜、瘦脸、磨皮、换脸、改五官；美颜与换正装作为**可选、默认关闭**的后续功能，并提示证件照审核风险。
- 不做生成式换脸/生成式换装/云端 GPU 推理；换正装只用本地模板对齐。
- 不做云端服务、账号体系、跨设备同步。
- 不打包 APK / IPA，不做小程序，不上架应用商店。
- 不做通用修图软件。
- 不承诺通过任何官方审核；规格与底色要求以报名系统当年的公告为准。

## 4. 反目标

- 任何照片上传到服务器。
- 修改人物本身的五官、肤色、脸型。
- 要求用户先安装运行环境、注册账号或付费。
- 为了“更智能”而牺牲可预测性：每个自动步骤都能手动覆盖。

## 5. 已定决策

| 决策 | 内容 |
|---|---|
| 形态 | 纯前端静态网页（HTML/CSS/JS + Canvas）；同一份文件可本机运行，也可作为 PWA 安装 |
| 主入口（电脑） | 双击 `启动.bat`：用 Windows 自带 PowerShell 起本地静态服务并自动开浏览器；手机连同一 Wi-Fi 可访问 |
| 备用入口 | 直接双击 `index.html`：可用的降级模式（无 AI、无 Worker），仅色键换底与基础导出 |
| 手机离线 | PWA + Service Worker：首次通过 HTTPS 链接打开并“添加到主屏幕”，之后缓存离线可用，电脑关机不影响 |
| 网络 | 电脑版完全本地；手机离线版首次需要一个 HTTPS 静态托管链接（用平台默认域名，不买域名），装好后离线 |
| 隐私 | 全部本地处理；除首次加载页面/模型外无网络请求 |
| 语言 | 中文界面 |
| 修改范围 | 默认只裁尺寸、只换底色；美颜/换正装为后续可选、默认关闭 |
| 手机 | 自己用；局域网（电脑需开着）或 PWA（电脑可关） |

## 6. 功能清单

### 6.1 导入

- 拖拽、点击选择、`Ctrl+V` 粘贴、手机相册/拍照。
- 支持 JPG、PNG、WebP、AVIF、HEIC（HEIC 用本地解码库）。
- EXIF 方向自动纠正；广色域（P3）统一转 sRGB 后再处理。
- 大图自动降采样用于预览与 AI 推理；导出时按目标像素从原图重采样。
- 导入后自动分析并在界面上提示：
  - 背景类型（纯色 / 复杂）；
  - 人脸数量与位置；
  - 原图分辨率是否足够目标尺寸（不够时提示“会糊”）；
  - 原底色是否已经等于目标底色（避免无意义重抠）。

### 6.2 裁剪与构图

- 目标尺寸预设（见第 8 节）+ 自定义 mm / px；宽高比锁定。
- 拖拽、缩放、移动裁剪框；三分/网格参考线；方向键微调。
- 人脸自动定位：头顶留白、眼睛线、左右居中；多脸时默认选最大脸，可点选切换。
- 头部参考线：按常见证件照比例显示（头顶留白约 8–12%、头部高度约 70%），可手动调整，不宣称官方合规。
- 旋转 90°；不提供镜像（证件照通常不允许）。
- 撤销 / 重做。

### 6.3 换底

- 底色预设：白、标准蓝、深蓝、红、浅灰；自定义取色器与 HEX 输入；可选渐变蓝。
- 双引擎，自动选择，也可手动切换：
  - **色键引擎**：从边框采样判断纯色背景，按颜色距离 + 边界连通生成蒙版。纯色底最干净、完全离线、速度快。
  - **AI 人像引擎**：人像分割模型生成 alpha 蒙版，适合复杂背景。
- 边缘后处理：羽化、去溢色（蓝边/红边）、蒙版收缩/扩张、轻微光影融合（避免“人贴在色板上”的塑料感）。
- 手动修补：橡皮擦 / 恢复笔，笔刷大小与软硬可调，支持放大。
- 边缘检查视图：棋盘格背景 + 放大镜，专门看发丝和边缘。
- 原图 / 结果对比切换。

### 6.4 导出

- 格式：JPG、PNG。
- JPG 质量可调，或“压到不超过 X KB”：只调质量、不缩尺寸；压不到时提示最低可达大小。
- 写入 DPI 元数据（JPG 改 JFIF density，PNG 写 pHYs）；导出统一 sRGB。
- 命名模板：`{姓名}_{规格}_{底色}_{宽}x{高}.jpg`，可修改。
- 单张导出。
- 全套导出：同一构图生成 一寸/二寸 × 红/蓝/白 六张，打包 zip。
- 排版打印：6 寸相纸（152×102mm）自动排布多张证件照，带裁切线，浏览器打印或存 PDF。
- 导出前预览与文件大小显示。

### 6.5 批量与全套

- 多选导入，统一规格/底色/压缩/命名，队列处理并显示进度，可取消。
- 每张自动检测人脸与背景；失败的照片标记出来，可单独打开修。
- 批量结果打包 zip；命名冲突自动加序号。

### 6.6 辅助

- 首次使用引导（三步：导入 → 裁剪/换底 → 导出）。
- 快捷键：撤销、重做、导出、对比、笔刷。
- 设置（最近使用的规格/底色/压缩值）保存在浏览器本地，不保存照片。
- 出错兜底：AI 模型加载失败或不可用时，提示并退回到色键 + 手动笔刷。

### 6.7 人像修饰（后续迭代，默认关闭）

- **美颜**：滑杆控制磨皮、去油光、提亮、均匀肤色、祛痘笔（手动点）、瘦脸、大眼、唇色；默认全部为 0；实时预览、随时对比原图、一键复位；界面标注“证件照报名可能不允许”。
- **智能换正装**：正装模板（男/女，黑/藏青/深灰，衬衫白/浅蓝，领带可选）+ 肩颈自动对齐 + 手动移动/缩放/旋转/擦除；保护脸、头发、手；**不做生成式换装**，只做本地模板合成。
- **衣物换色**：手动/自动选区 + 保留明暗褶皱的换色；白→黑呈现哑光效果，深→浅难度更高。
- 以上全部默认关闭、可撤销；导出默认保持原样。

## 7. 操作流程

导入 → 自动分析（背景/人脸/分辨率）→ 裁剪与定位 → 选底色 → 边缘检查与修补 → 压缩/命名 → 导出（单张 / 全套 / 批量 / 排版）。

## 9. 技术方案

### 9.1 总体

- 原生 HTML/CSS/JS + Canvas 2D，不引入前端框架，交付物不需要构建步骤。
- 使用传统 `<script>`（非 ES Module），保证 `file://` 直接打开时也能加载脚本。
- AI 推理与重计算放进 Web Worker（**后续迭代，v1 未实现**），主线程保持界面响应。
- 第三方库全部本地引入并固定版本：HEIC 解码、zip 打包、AI 运行时/模型；许可需允许个人使用，并在 README 记录。

### 9.2 目录结构（示意）

```
id-photo-studio/
├─ 启动.bat
├─ server.ps1
├─ index.html
├─ styles.css
├─ app.js              # v1：界面、状态、色键、AI、导出都在一个 IIFE 里
├─ specs.js            # 规格与颜色预设
├─ sw.js
├─ manifest.webmanifest
├─ icons/
├─ vendor/             # 本地库与模型
├─ docs/               # DESIGN.md / ENGINEERING.md / demo / images
├─ tests/
├─ README.md
└─ LICENSE
```

> v1 实际采用单文件 `app.js`；设计稿里曾计划的 `app/` 模块拆分与 `worker.js` 没有实现，工作画布和 AI 推理都在主线程完成。

### 9.3 抠图双引擎

- **纯色底**：边框带采样 → 聚类得到主色与方差 → 判为纯色则用颜色距离生成软蒙版 → 从边框洪水填充去掉内部误判 → 用原图引导滤波细化边缘 → 按估计的背景色去溢色。
- **复杂背景**：AI 模型输出 alpha → 上采样 → 用原图引导滤波/边缘细化 → 去溢色 → 合成。
- **模型策略**：
  - 内置轻量模型：体积小、离线、速度快，作为默认；
  - 可选高质量模型：首次联网下载约 25–40MB，缓存后可离线，发丝边缘更好；
  - 候选：MediaPipe Selfie Segmenter（轻量）、MODNet / RMBG / @imgly background-removal（高质量）；实现时用样张对比选定，并核对许可。
- **兜底**：模型加载失败、离线且未缓存、或照片不是人像时，自动退回色键 + 手动笔刷，并明确提示。

### 9.4 人脸与构图

- 人脸检测取人脸框与眼睛位置（MediaPipe Face Detector 或同级方案）。
- 按“头顶留白 + 眼睛线 + 居中”自动摆放裁剪框；多脸取最大，可手动点选。
- 检测失败时退回手动裁剪，不阻塞流程。

### 9.5 像素、DPI、压缩

- 像素换算：`px = round(mm / 25.4 × dpi)`；自定义支持 mm 或 px 输入。
- JPEG DPI：在编码后的 JFIF APP0 段写入 300/350 dpi；PNG 写入 pHYs（ppm = dpi / 0.0254）。
- 目标 KB（仅 JPG；PNG 为无损格式）：在质量 0.3–0.95 之间二分搜索，取不超过目标值的最大质量；达不到时显示最低可达大小。
- 大图导出：按目标像素从原图重采样，避免先缩后放。
- 色彩：导入时统一转 sRGB；导出不带多余元数据。

### 9.6 本地启动器

- `启动.bat` 调用 `server.ps1`，用 PowerShell 的 `TcpListener` 实现最小静态服务器（无需管理员、无需 Python），绑定 `0.0.0.0`，端口被占用时自动顺延。
- 自动打开默认浏览器；控制台打印本机与局域网访问地址，手机连同一 Wi-Fi 即可打开。
- 只提供静态文件读取，不提供上传接口；使用应用文件白名单，`.git/`、`.work/`、`tests/` 等路径返回 404。Windows 防火墙首次放行需用户在弹窗确认（README 说明）。
- 直接双击 `index.html` 为降级模式：色键、裁剪、导出可用；AI 不可用（v1 也没有 Worker），界面明确提示“用启动脚本打开以启用 AI 抠图”。

### 9.7 PWA 与离线（手机）

- `manifest.webmanifest` + 图标 + `sw.js`。
- Service Worker 首次在 HTTPS 下打开时预缓存：页面、样式、脚本、PWA 清单、图标、HEIC 解码库、MediaPipe vision bundle、当前浏览器对应的 SIMD/非 SIMD wasm、人像/人脸模型（约 16MB）。
- 之后 cache-first：页面、换底、AI 全部离线可用；只有首次安装/更新需要联网。
- 手机通过系统浏览器“添加到主屏幕”（Android Chrome 安装应用；iOS Safari 分享 → 添加到主屏幕）。
- 局域网 HTTP 不是安全上下文，Service Worker 无法注册；因此“手机离线、电脑关机”必须走 HTTPS 静态托管。托管只提供静态文件，不做任何计算。
- 托管成功打开一次即可安装；安装后宿主访问不了也不影响已缓存的版本。更新时重新部署并联网打开一次。

### 9.8 隐私与网络

- 照片只在浏览器内存中处理，不写入服务器、不上传。
- 除首次加载页面/模型外，预期没有任何网络请求；验收时用开发者工具网络面板确认。
- 不引入统计、埋点、账号、Cookie 追踪。
- 设置保存在浏览器本地；照片不持久化。

## 11. 验收标准

1. 双击 `启动.bat` 后浏览器自动打开，全程不需要安装 Python/Node；手机在同一 Wi-Fi 下能打开并完成一次导出。
2. JPG、PNG、HEIC 均可导入；竖拍照片方向正确；P3 照片颜色无明显偏色。
3. 蓝底换白底，在 200% 放大下头发边缘无明显蓝边。
4. 复杂背景照片能自动抠出人像；发丝不完美时可用笔刷修好；失败有明确提示。
5. 预设导出像素与表中一致；JPG 的 DPI 为 300/350；JPG 目标 KB 在可行时误差 ≤ 1KB。
6. 全套导出生成 6 张图 + zip；排版图按 6 寸相纸实际尺寸打印，量尺误差 ≤ 1mm。
7. 批量 10 张可完成，失败项有标记且可单独处理。
8. 首次加载完成后断网仍可用（模型已缓存/本地）。
9. 除模型下载外无网络请求。
10. 除了裁剪和换底，人物五官、脸型、肤色不做改变。

## 12. 测试计划

- **单元测试**（纯函数）：mm/px 换算、JPG 目标 KB 二分、命名模板、颜色距离与蒙版计算、规格数据校验。
- **样张矩阵**：纯蓝底、纯白底、纯红底、复杂户外、卷发、戴眼镜、多人合影、HEIC、200px 低分辨率、4800 万像素大图、截图、非人像。
- **手工清单**：每个功能按第 11 节验收标准逐条过；桌面 Chrome/Edge 必测，Safari 尽力。
- **可选自动化**：环境允许时用 Playwright 跑导入→裁剪→换底→导出的冒烟流程。
- **回归**：每次改动后至少跑单元测试 + 关键样张。

## 13. 风险与对策

| 风险 | 对策 |
|---|---|
| AI 发丝边缘质量不够 | 双引擎 + 手动笔刷 + 可选高质量模型；实现时用样张对比选型 |
| 模型体积大、手机慢 | 轻量模型默认；高质量按需下载；推理降采样（Worker 为后续迭代） |
| 浏览器差异（Safari/微信） | 主目标 Chrome/Edge；检测到受限环境时提示换浏览器 |
| `file://` 限制 | 主入口走本地服务；直开 HTML 作为降级模式并提示 |
| 规格随年份变化 | 预设可编辑 + 明确免责声明 + 保留自定义 |
| 模型/库许可问题 | 只用允许个人使用的方案，README 记录来源与许可 |
| 本地服务被同网设备访问 | 只读静态服务、无上传接口；README 说明；可改成仅 localhost |
| DPI 元数据写入出错 | 单元测试校验 JPG/PNG 头部；打印尺寸实测 |

## 14. 留给实现的决定

- 具体 AI 模型与运行时（按质量、体积、许可、手机性能对比后选定）。

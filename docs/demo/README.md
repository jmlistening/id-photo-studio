# Demo assets

`synthetic-portrait.svg` is a programmatically drawn illustration used only for README screenshots and manual UI testing.

- It does **not** depict a real person.
- It contains no photo metadata, EXIF, or personal information.
- It is rendered at 1800×2400 with headless Chrome for the screenshots in `docs/images/`.
- It is licensed under the same MIT license as the rest of this repository.

The app's own `?demo=1` mode uses a separate, simpler canvas-drawn figure in `app.js`; that figure is also synthetic.
